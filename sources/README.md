## 使用方式

- Wiki 筆記和簡報中的關鍵主張使用來源 ID，並連到對應來源紀錄。
- 摘要未交代的細節不自行補齊；必要時回到全文查核。
- 每篇來源只支持其研究設計和受試者範圍內的結論；不可把單一短期試驗寫成普遍定律。
